# Changelog

## 0.2.0

### Listening room
- Live browser-tab audio, local-file playback, and a built-in stereo speaker test.
- QR invitations and host network selection.
- Speaker naming, volume, mute, stereo roles, and timing adjustment.
- Adjustable live buffering and continuous laptop playback with persistent resampling.
- Three-band equalizer, six presets, bypass/reset, and room-wide defaults for new joins.
- Output headroom and compression.

### Windows distribution
- Double-click Run and Stop launchers with automatic host-invitation opening.
- Authenticated instance checks and duplicate-server prevention.
- Portable Windows x64 ZIP with the runtime, licenses, and per-file checksums.

### Validation
- Audio timing, rendered waveform, access control, EQ, QR, and client regression tests.
- Extracted-package smoke testing without Node on PATH.
